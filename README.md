# QR Code Generator

## About the Project
QR Code Generator is a simple web application developed using HTML, CSS, and JavaScript. It allows users to enter text or a URL and generate a QR code instantly.

## Technologies Used
- HTML
- CSS
- JavaScript
- VS Code

## Features
- Generate QR code from text
- Generate QR code from URL
- Simple and user-friendly interface
- Fast QR code generation
- Responsive design

## How It Works
1. Enter text or a URL in the input box.
2. Click on the Generate QR Code button.
3. The QR code will be displayed on the screen.
4. Scan the QR code using a mobile device.

## Skills Used
- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Handling
- Basic Frontend Development

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in a browser.
4. Enter text or URL and generate the QR code.
